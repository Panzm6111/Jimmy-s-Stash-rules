# 手机简明使用教程

**已经能用本项目的用户，现在只需要更新原配置链接。** 主配置版本为`AD-20261020.2`，已整合已审查的App去广告动作和响应脚本，并默认引用扩展广告域名规则。自动签到继续暂停。真实iPhone上的去广告和正常业务效果仍需验收。

## 已经能用：四步更新

1. 保留能用的配置备份、原本机私人订阅覆写、已信任证书和地区选择。**不重填机场URL、不新建私人覆写、不重装证书。**
2. 如果之前另装过“广告增强”、某App广告覆写、expanded或临时诊断覆写，先停用这些额外广告条目；没装过就跳过。私人订阅覆写继续启用。
3. 在Stash配置列表，更新原来的Jimmy公共配置，地址仍然是：

```text
https://raw.githubusercontent.com/Panzm6111/Jimmy-s-Stash-rules/main/config/stash.yaml
```

4. 在配置文本开头看到`AD-20261020.2`后，选中它，保持HTTP/MITM开启，断开再连接Stash。核对节点仍在、总代理和各软件仍是自己要用的地区。

不用再添加App模块或expanded。**所谓“App开关”原来指自行导入的覆写条目，不是Stash自带按钮；推荐整合配置没有逐App开关。** 脚本已随主配置下载，扩展规则集由配置自动引用。规则集若报下载错误，可到远程规则集手动刷新“基础广告”；这是保留的名称，实际引用的是扩展包。

## 第一次安装

按[完整订阅教程](SUBSCRIBE.md)导入上面的公共URL，在设备只填一次自己的机场订阅到本地私人覆写。公共配置不知道你的私人订阅，不能把机场token拼在公共URL后。安装成功后保留这份私人覆写，以后公共更新继续使用它。

刷新“机场”，核对SS/VLESS等真实节点数，排除流量和到期提示。把“总代理”从初始REJECT改为“自动节点”或有节点的所需地区，使用规则模式连接。想手选具体节点，用“手动节点”；各软件可独立选地区或跟随总代理。海外AI默认美国，Apple/Microsoft默认DIRECT，已有UI选择可能覆盖文件默认。

HTTP去广告首次才需要在Stash生成自己的CA、按提示安装，并到iOS“设置→通用→关于本机→证书信任设置”完全信任；已有证书不用重做。不扩大解密到全域名或支付/银行主域，不关闭TLS验证，私钥只留设备。

## 平时更新与效果检查

以后刷新同一公共主配置，即可取得新的分流、App声明与内嵌脚本。机场和扩展规则集分别按配置的24小时间隔尝试刷新，断网时不能更新；不承诺主配置本身每天自动拉取。更新后检查私人覆写关联和地区选择，丢失时按自己的本机记录恢复。

每款App多次检查冷启动、后台返回、触发预加载后再启动，记录广告、空白页、倒计时和加载时长变化。同时检查登录、搜索、消息、视频和普通领券；一次无广告不能证明成功。广告可能来自旧缓存或当前未覆盖端点，网络规则不能删除App本地缓存，优先使用App自己的清缓存入口。

## 出现异常怎么恢复

- 登录、消息或播放等异常：先将“广告拦截”改成DIRECT排查域名拦截；仍异常，再关闭HTTP/MITM并重连。DIRECT不会关闭HTTP脚本。
- 全部断网、配置报错：切回设备保存的可用配置，保留原私人订阅。不要把报错通过关闭TLS校验掩盖。
- 需要长期单独开关某App：另选[原分层安装](../README.md#可选原分层方式安装)，再逐个导入App覆写。普通使用无需走这条路线。
- 仍有广告：按[诊断说明](ADBLOCKING.md#用固定日志判断运行到哪一步)反馈固定状态、App及广告位置，不发完整私人配置、URL查询参数、Cookie、正文或证书。

[本地ZIP](LOCAL-IMPORT.md)和原分层模式保留为备选，不是推荐订阅的额外步骤。更多更新边界见[更新教程](UPDATES.md)，完整真机检查见[验收清单](PHONE-CHECKLIST.md)。
