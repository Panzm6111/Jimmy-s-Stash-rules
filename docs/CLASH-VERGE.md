# Clash Verge 使用方法

## 完整自动订阅（推荐）

这是唯一的Clash发布入口：

```text
https://raw.githubusercontent.com/Panzm6111/Jimmy-s-Stash-rules/main/config/clash-verge-auto.yaml
```

主订阅包含 23 个策略组、1 个隐藏下载回退组和 33 个规则集。海外AI 的 ai 池为新加坡 A、荷兰、英国 B（250 ms）；TikTok 的 AI最速池另含日本 A/B、美国 C/D（100 ms）；总代理默认最速节点，为 HKG A/B/C/I/J/M、日本 A/B、荷兰、新加坡 A、英国 B（50 ms）。Stash 前两项分别经「GPT 服务优选」「TikTok 服务优选」，Clash 直接选对应池。

GPT 与 TikTok 入口按网址各自探测，刷新原主订阅即可使用；先确认两个业务选的是对应自动池且未固定具体出口。Stash 的本机覆写不适用于 Clash。详见[服务检测边界](ROUTING.md#iphone-service-health)。

### 2026-11-02 自动选择防误触

当前 10 个 url-test 自动池设置 hidden；业务组只展示策略选项，具体节点集中到“Jimmy · 手动节点”。组名和原默认出口保持不变。多个业务选择同一个手动入口时，共享该入口的节点选择。Clash的隐藏仅用于界面防误触，嵌套展开、其他面板或内核API仍可能固定节点，不是强制自动锁。

更新前，先在旧配置的自动池里取消已有图钉：Clash Verge 2.5.8可再次点击当前固定节点解除，至少核对“Jimmy · ai”和“Jimmy · 自动节点”。随后刷新原主订阅，再确认“海外AI”选择所需的ai或地区池。隐藏本身不会清除已经保存的固定状态；如果已经刷新到隐藏版，对可展开的该自动池执行组级主动延迟测试可解除固定，再确认图钉消失；无法找到该入口时先只读确认状态，不盲目改设置。不要通过重置整个配置来清除固定，这会影响私人设置。

三个精选池均设为每 60 秒主动检查；其余七个常规池的组配置为 1800 秒、50 ms。Clash 机场另每 60 秒做通用 HTTP 204 检查（5 秒超时）；ai 和 AI最速分别按 ChatGPT、TikTok 入口的 HTTP 200 记录独立健康状态。Stash 的原生测速结果按节点共用，启用本机服务检测后才会按业务分别判断。容差是两条健康线路之间的延迟差，不是故障等待时间。 原有手动图钉可能覆盖自动选择。探测成功后，GPT 账号及 TikTok 的地区可用性仍要在应用中确认。

小红书、抖音和东方财富的完整上游分类前置保护为DIRECT；抖音补充分类先于旧TikTok补充，修复aweme.snssdk.com误入TikTok的问题。TikTok专属功能分类优先于国内分类，评论与内容仍交给TikTok组。共享国内分类中的部分广告域名也会被放行；Stash的明确App广告与HTTP处理仍保留。代表性检查及边界见[分流说明](ROUTING.md)。

### 已使用“Jimmy 全自动”

保留原卡片与私人Merge，更新原主订阅即可。自动更新开启，间隔1440分钟；机场和规则集按86400秒尝试更新。仅更新规则集不能取得新的策略组结构。

### 首次接入

1. 导入上面的URL，并开启1440分钟自动更新。保留原可用配置作为设备备份。
2. 在这张卡片的私人Merge中保留原机场URL、私人节点启动后备、DNS及个人设置。私人Merge不放Jimmy的rules、proxy-groups、rule-providers。
3. 全局Merge中不再粘贴旧Jimmy路由；已有其他个人设置时只移除旧Jimmy结构，不清空无关设置。
4. 由用户选择何时应用，避免切换影响当前网络。查看“代理集 → 机场”的节点数及成功时间，再核对软件出口。

若机场必须经代理才能下载，可在可信本机用原机场配置生成私人启动后备：

```text
python -X utf8 tools/prepare_clash_bootstrap.py --airport <原机场本地YAML> --merge <私人Merge> --output <新的本地私人文件>
```

输出包含节点凭据，只留本机，不上传GitHub或第三方转换站。工具保留节点和个人设置，移除旧固定下载代理；公共配置使用隐藏fallback组自动选择可用出口，60秒通用健康检查，不固定依赖某一个日本节点。

下载失败时，首次无缓存需要先有本机后备。已有后备和缓存的保留行为已做Mihomo模拟，真实机场是否可用仍取决于网络、节点与账号。代理组的HTTPS测速不代表TikTok/AI一定可用。
