# 粘贴链接导入Stash

推荐使用这一条固定公共配置链接：

```text
https://raw.githubusercontent.com/Panzm6111/Jimmy-s-Stash-rules/main/config/stash.yaml
```

它包含16个策略组、5个地区池、国内/局域网直连、基础域名广告规则和已做好的40款App专项。所有规则和11份独立脚本已内嵌，不必逐个导入广告模块，也不使用订阅转换网站。扩展38,066条域名包保留为可选，默认使用原基础包。

## 第一次使用

1. 保留原来能用的配置。在Stash配置管理选择“从URL/链接下载”（菜单文字随版本可能不同），粘贴上面的完整地址，下载后选择这份配置。
2. 在设备准备一份**本地私人覆写**，只在手机填写自己的机场URL，启用并关联这份配置。可从仓库的[占位模板](../examples/private-provider.stoverride)下载为本地文件，或使用Stash提供的本地覆写编辑入口；不要保留模板的远程更新关系。可复制的内容如下，把最后一行替换为本人订阅，其他名称不变：

```yaml
name: 本机私人订阅
proxy-providers:
  机场:
    url: https://example.invalid/REPLACE_ON_DEVICE
```

3. 检查合并预览：只有一个“机场”代理集、URL是本机值、16个项目组不重复。刷新“机场”，对照后台核对SS/VLESS等节点数；把“总代理”从REJECT改为需要的地区，以“规则模式”连接。若要开屏专项，先完成下述证书设置再测试相关App。

这条公共链接负责配置，你自己的机场订阅负责节点。公共配置不会自动知道你的订阅；机场URL只需在本机填一次。不要把机场URL/token拼在公共链接后，也不要提交到GitHub或发送给维护者。格式及节点遗漏问题见[订阅兼容说明](SUBSCRIPTION.md)。

## 开屏专项的一次性证书设置

本入口已经合并40款专项的12条响应handler、32条HTTP重写、41个精确MITM主机。是否生效取决于Stash的HTTP/MITM设置、设备证书、App版本与缓存，不是下载后就已经完成去广告验收。

在Stash本机生成CA并按提示安装；再到iOS“设置→通用→关于本机→证书信任设置”信任自己的证书，回Stash设置HTTP/MITM。证书私钥只留在设备，不安装他人CA、不关闭TLS验证。

具体主机和处理范围见[模块目录](AD-MODULES.md)。虽然脚本只改广告路径，MITM解密范围仍是整个指定主机；不解密银行/支付主域。微信公众号仅文章广告，不含朋友圈/视频号。若只要基础域名去广告，可停用Stash的HTTP/MITM处理，保留规则分流。具体开关位置以当前Stash版本为准。

这是一体化启用方式。需要逐款独立启停时，改用[本地包](LOCAL-IMPORT.md)的基础主配置搭配单App模块，或原公共core分层模式；不要在一体化配置上重复叠加同款handler。遇到异常先停HTTP/MITM；域名误拦再把“广告拦截”改DIRECT。DIRECT不能停止HTTP脚本/重写。

## 选地区与日常更新

OpenAI/Netflix/YouTube/Telegram默认跟随总代理，也可各自选择美国、日本、香港、新加坡、台湾地区池或独立具体节点。Apple/Microsoft默认直连；测速变绿不等于服务解锁，地区池全失效行为仍需真实Stash验证。

以后在配置列表刷新**同一条URL**即可获取这份入口内嵌的公共规则/脚本新快照，不重建本机私人覆写。机场代理集按其interval另外刷新；不假设主配置每天自动更新。刷新后检查本机覆写仍关联、机场URL仍是私人值、原组名及各软件选择仍在。界面选择和证书是否保留尚未实测；先记下选择，在设备保留私人备份，必要时重选/重新关联。

不要直接在会被远程刷新整份替换的公共主配置里长期保存私人URL。若当前版本无法方便使用本地私人覆写，也可先编辑下载后的主配置作为试用，但每次重新下载前都须备份并在本机重新填URL，不能承诺这种做法自动保留。

更新失败时保留当前已下载配置，不删原来能用的配置。若需要回退，使用自己本机已验收过的旧配置，或从仓库历史提交取得旧的公共配置入口，再关联原私人覆写。含真实订阅或证书的备份不上传。

## 验证边界

固定URL已实际返回HTTP 200，下载内容与发布文件逐字一致；64/64个公共运行资源均通过HTTP和哈希检查，记录见[PROGRESS.md](../PROGRESS.md)。普通YAML/模型通过仍不等于Stash原生解析、代理连接、地区锁定、广告效果或界面选择保留已经通过。当前官方文档站受云网络策略限制，精确版本和部分原生语义待复核。手机检查见[验收清单](PHONE-CHECKLIST.md)。自动签到继续暂停。

维护者更新原配置/规则/脚本后，运行`python tools/build_subscription.py --write`重建同一入口，再执行`python tools/validate.py`。构建只改变承载方式，不另维护第二套业务逻辑。
