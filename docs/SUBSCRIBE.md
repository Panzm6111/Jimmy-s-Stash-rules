# 粘贴链接导入Stash

推荐使用这一条固定公共配置链接：

```text
https://raw.githubusercontent.com/Panzm6111/Jimmy-s-Stash-rules/main/config/stash.yaml
```

它包含18个策略组、5个地区池、“其他地区”和不分组的“全部节点”，以及国内/局域网直连、基础域名广告规则和40款候选App专项。规则已内嵌，12份独立脚本由Stash按本仓库稳定URL下载，不必逐个导入广告模块，也不使用订阅转换网站。脚本初次下载需要联网；可选本地包仍保留内嵌脚本方式。扩展38,066条域名包保留为可选，默认使用原基础包。

## 第一次使用

1. 保留原来能用的配置。在Stash配置管理选择“从URL/链接下载”（菜单文字随版本可能不同），粘贴上面的完整地址。下载后把它命名为“Jimmy 本机配置”并明确选中它；机场链接应填写到下一步的代理集中，不能另外把机场生成的整份配置当作本项目主配置运行。
2. 在设备准备一份**本地私人覆写**，只在手机填写自己的机场URL，启用并关联这份配置。可从仓库的[占位模板](../examples/private-provider.stoverride)下载为本地文件，或使用Stash提供的本地覆写编辑入口；不要保留模板的远程更新关系。可复制的内容如下，把最后一行替换为本人订阅，其他名称不变：

```yaml
name: 本机私人订阅
proxy-providers:
  机场:
    url: https://example.invalid/REPLACE_ON_DEVICE
```

3. 暂停无关的旧覆写，检查最终合并预览：只有一个“机场”代理集、URL是本机值、18个项目组不重复。刷新“机场”，对照后台核对SS/VLESS等真实节点数，不把流量和到期提示算成节点。先在“全部节点”选一个真实节点，再把“总代理”改为“全部节点”，用“规则模式”测试普通HTTPS网站；确认能连接后，再按需改选地区池。若要开屏专项，先完成下述证书设置再测试相关App。

这条公共链接负责配置，你自己的机场订阅负责节点。公共配置不会自动知道你的订阅；机场URL只需在本机填一次。不要把机场URL/token拼在公共链接后，也不要提交到GitHub或发送给维护者。格式及节点遗漏问题见[订阅兼容说明](SUBSCRIPTION.md)。

## 已有完整机场文件：合成一个本机导入文件

若私人覆写或代理集导入无法工作，可使用已经包含实际 `proxies` 的完整机场 YAML，在可信的本地电脑合成一个文件。手机用户拿到合成结果后直接导入，不需要执行下面的开发命令，也不再填写私人覆写。

```sh
python tools/build_private_config.py --input /tmp/airport.yaml --output /tmp/Jimmy-Stash-private.yaml
```

输入和输出必须放在仓库外，不使用真实订阅URL作为命令参数。工具不联网、不打印节点名/服务器/凭据，不将私人文件加入Git，输出权限为0600。它只取来源节点，保留每个节点的连接字段；常见流量/到期提示不作节点，重复名称报错，与策略组重名的节点仅加显示前缀。Reality/Vision等字段会原样保留，但不因此宣称Stash支持或已经连接成功。带链式代理依赖的来源需要另行审查，不静默删除依赖。

分流、DNS及40款广告专项继续复用当前 `config/stash.yaml`，不继承机场旧DNS、策略组、规则、控制端口或证书。代理集引用和筛选在构建时展开为明确节点列表；“其他地区”在这个**固定快照**里是五地区之外的全部候选，名称无法识别的节点也包含在内。空地区只含REJECT，非空地区只列本地区候选和末尾REJECT；全部失效的原生行为仍待手机验收。

导入时选择这个新文件作为主配置，关闭之前为了本项目启用的覆写，保持规则模式。首次在“全部节点”手选真实节点，再将“总代理”从REJECT改为“全部节点”，或直接选择有节点的地区。HTTP/MITM证书步骤与下节相同。

**这是本地节点与规则快照，不能自动更新机场节点或内嵌分流规则。** 机场变化后需取得新的完整文件，再用同一工具和当前公共源文件重新合成；脚本仍由Stash按本仓库URL获取。不要将原机场的远程更新地址绑定到合成结果，否则刷新会替换回机场原分流。更新前保留旧文件和地区选择，失败时切回之前能用的配置。私人结果不上传公开仓库，也不公开托管下载。

## 开屏专项的一次性证书设置

本入口已经合并40款专项的18条请求handler、10条响应handler、16条HTTP重写、41个精确MITM主机。是否生效取决于Stash的HTTP/MITM设置、设备证书、App版本与缓存，不是下载后就已经完成去广告验收。

在Stash本机生成CA并按提示安装；再到iOS“设置→通用→关于本机→证书信任设置”信任自己的证书，回Stash设置HTTP/MITM。证书私钥只留在设备，不安装他人CA、不关闭TLS验证。

具体主机和处理范围见[模块目录](AD-MODULES.md)。虽然脚本只改广告路径，MITM解密范围仍是整个指定主机；不解密银行/支付主域。微信公众号仅文章广告，不含朋友圈/视频号。若只要基础域名去广告，可停用Stash的HTTP/MITM处理，保留规则分流。具体开关位置以当前Stash版本为准。

这是一体化启用方式。需要逐款独立启停时，改用[本地包](LOCAL-IMPORT.md)的基础主配置搭配单App模块，或原公共core分层模式；不要在一体化配置上重复叠加同款handler。遇到异常先停HTTP/MITM；域名误拦再把“广告拦截”改DIRECT。DIRECT不能停止HTTP脚本/重写。

## 选地区与日常更新

OpenAI/Netflix/YouTube/Telegram默认跟随总代理，也可各自选择美国、日本、香港、新加坡、台湾地区池、“其他地区”、“全部节点”或独立具体节点。“全部节点”平铺连接候选，排除常见流量/到期提示，不按国家拆分，也不按SS/VLESS协议删节点；无法按名称归类时到这里找。它与保留的旧“手动节点”都是共享选择入口，需要各软件互不影响时，直接在软件组内选具体节点。Apple/Microsoft默认直连；测速变绿不等于服务解锁，地区池全失效行为仍需真实Stash验证。

“其他地区”按常见其他国家和地区的中文、英文、缩写、旗帜正向匹配，例如韩国、英国、德国、加拿大、澳大利亚等；它不是五个地区的严格补集，名称含糊或未收录的节点仍在“全部节点”。为了避免依赖未经核实的排除字段，本项目没有使用负向前瞻或`exclude-filter`。

以后在配置列表刷新**同一条URL**即可获取入口内嵌规则、策略组及脚本声明的新快照，不重建本机私人覆写。脚本与机场代理集分别配置每日刷新请求；不假设主配置每天自动更新，也不承诺离线缓存必然存在。刷新后检查本机覆写仍关联、机场URL仍是私人值、原组名及各软件选择仍在。界面选择和证书是否保留尚未实测；先记下选择，在设备保留私人备份，必要时重选/重新关联。

不要直接在会被远程刷新整份替换的公共主配置里长期保存私人URL。若当前版本无法方便使用本地私人覆写，也可先编辑下载后的主配置作为试用，但每次重新下载前都须备份并在本机重新填URL，不能承诺这种做法自动保留。

更新失败时保留当前已下载配置，不删原来能用的配置。若需要回退，使用自己本机已验收过的旧配置，或从仓库历史提交取得旧的公共配置入口，再关联原私人覆写。含真实订阅或证书的备份不上传。

## 已启动但打不开网页或出现DNS证书错误

先检查选中的是否是“Jimmy 本机配置”。本项目没有名为“Google”或“NCloud”的策略组，也未配置四个fallback DNS；如果最终配置里出现这些内容，先停用无关覆写，核对是否运行了机场生成的整份配置、旧配置，或其他本机设置覆盖了公共文件。仅凭这些名称不能确定唯一原因，应以最终合并结果为准。日志显示runtime started只证明当时有配置启动，不能反推Jimmy配置导入成功；若导入页面另有解析错误，需单独记录该错误的字段和行号。

本项目使用以下两个加密DNS地址：

```text
https://dns.alidns.com/dns-query
https://doh.pub/dns-query
```

若错误涉及 `dot.pub` 和 `NotValidForName`，表示连接时的证书名称核对未通过；它不是让你关闭证书验证的提示。本项目没有使用 `dot.pub`。同时检查Stash界面的DNS设置、已启用覆写与最终YAML，恢复以上地址，不开启 `skip-cert-verify`，也不把更换MITM证书当作DNS证书错误的修复方法。网络拦截、DNS服务端、系统时间及其他设置也可能造成TLS问题，不能把所有DNS错误都归因于主配置。

DNS设置核对后，先关闭HTTP/MITM处理，用“全部节点”手选一个真实节点测试普通HTTPS网站；不要选“剩余流量”“到期时间”等提示项。基础连接成功后，再逐步启用地区池和广告处理。仍失败时，只反馈Stash/iOS版本、选中配置名称、错误类别、问题发生在导入/启动/连接哪一步，以及是否含 `NotValidForName`；不要发送原始完整日志或含私人信息的截图。

## 验证边界

固定URL已实际返回HTTP 200，下载内容与发布文件逐字一致；64/64个公共运行资源均通过HTTP和哈希检查，记录见[PROGRESS.md](../PROGRESS.md)。普通YAML/模型通过仍不等于Stash原生解析、代理连接、地区锁定、广告效果或界面选择保留已经通过。当前官方文档站受云网络策略限制，精确版本和部分原生语义待复核。手机检查见[验收清单](PHONE-CHECKLIST.md)。自动签到继续暂停。

维护者更新原配置/规则/脚本后，运行`python tools/build_subscription.py --write`重建同一入口，再执行`python tools/validate.py`。构建只改变承载方式，不另维护第二套业务逻辑。
