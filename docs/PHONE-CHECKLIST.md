# iPhone 验收清单与反馈

本清单验收当前整合入口`config/stash.yaml`。逐App开关已按用户决定取消，不再作为缺失功能或验收项；现有专项仍需分别检查实际广告与正常业务效果。发布情况见[进度记录](../PROGRESS.md)。官方文档阻塞与原生能力复核仍需处理，没有你的手机与账号，维护者不能代勾以下项目。

- [ ] 整合入口：原config/stash.yaml刷新后可见AD-20261020.2；App动作、11份脚本content与精确MITM主机已内嵌，无需额外广告覆写。已另装的整合增强/App/expanded/诊断覆写停用，私人订阅覆写保留；没有同一路径重复处理。不分享私人预览。
- [ ] 推荐入口默认“基础广告”provider指向rules/vendor/ads-expanded.yaml，存在真实RULE-SET引用并下载成功；局域网、Apple通知、Microsoft登录和私人白名单优先。无需另加expanded覆写，不将完整静态规则文件前插当广告模块。

- [ ] 记录 iOS/Stash 版本；明确选中“Jimmy 本机配置”，暂停无关覆写，Stash真正接受该配置；最终合并预览含18个项目组且无重复/循环，只有一个“机场”代理集。若出现“Google”“NCloud”等本项目没有的组，先检查当前配置与覆写来源。
- [ ] 最终生效DNS为 `https://dns.alidns.com/dns-query`、`https://doh.pub/dns-query`；检查界面DNS设置与覆写是否覆盖YAML。本项目未使用 `dot.pub` 或四个fallback DNS。遇到 `NotValidForName` 按[教程](SUBSCRIBE.md#已启动但打不开网页或出现dns证书错误)检查，不关闭TLS验证；不能据此断定所有故障均来自本配置。
- [ ] 机场只在本机填写，刷新成功；排除常见流量/到期提示后，“自动节点”和“手动节点”的真实节点总数及SS/VLESS数与机场后台一致。至少各测一种实际存在的协议；不把提示项和本仓库假节点当真实节点，不按协议静默删节点。
- [ ] 先关HTTP/MITM，在“手动节点”手选一个真实节点，总代理选“手动节点”，普通海外HTTPS可连接；再切到自己选择的地区。延迟正常之后另测所需业务。
- [ ] “自动节点”和“手动节点”均展示全部连接候选；“其他地区”包含常见其他国家名称，不是严格补集。名称不规范、地区未收录的节点能在这两个全池入口找到。对照后台确认没有遗漏真实节点；五个地区的成员核对真实出口，命名多地区或不明确时不凭名字确认归属。已知提示前缀被过滤，未知提示仍不应当作节点。
- [ ] 7个自动池（自动节点、五单地区、其他地区）均为url-test，检查间隔1800秒；观察自动选择是否依据HTTPS探测延迟，记录原生切换阈值/缓存/时机尚未验证的部分。“自动节点”可能换国家，“其他地区”可能在其多国候选内切换；“手动节点”仍可手选全池。直接在两个软件组里各选具体节点时互不影响，跟随同一池则共用结果。
- [ ] 海外AI 与 Netflix 各选不同地区，调整其中一个不会改变另一个；改总代理只影响选“总代理”的软件。
- [ ] 在机场确实没有某地区节点时选择该池，确认访问被拒绝，**没有直连或其他地区出口**。若各池都有节点，可在本机临时副本中用不可能匹配的地区 filter 测试，保留 `^REJECT$`，测完删副本，不改仓库主文件。
- [ ] 在本机临时副本把“机场”替换为只含测试地址 `192.0.2.1` 的模拟节点（仅测试组使用），确认全失效也拒绝。不使用任何真人凭据、不改生产订阅、不为测试关闭证书验证。不会做这项可报告“未测”，不能凭离线工具代勾。
- [ ] 检查国内站、局域网设备、Apple通知/iCloud、Microsoft登录/常用服务的预期路径；规则显示的是域名匹配，不代表识别完整 App。
- [ ] 整合入口默认扩展广告，测试本人常用App的登录、手动支付页面、消息、正常播放、领券。发现误拦用广告组DIRECT对照并检查精确白名单，不因规则数量多就勾选通过。
- [ ] 需要HTTP处理时保持HTTP/MITM开启，核对[模块目录](AD-MODULES.md)对应的精确域名、handler与url-rewrite已在主配置中。用户已有完全信任CA，无需重装。分别测试广告效果和正常功能；无效时按诊断说明定位，不能标“已去除”。不用逐款导入或启用模块。
- [ ] 逐款多轮测试冷启动、后台返回、使用触发预加载后再启动；可对照广告组DIRECT加HTTP/MITM关闭，或保留的修改前配置。结合命中记录，广告频控下单次无广告不判成功。记录广告是否消失、是否出现空白/倒计时/更长等待；再测正常登录、支付、消息、播放、查物流/定位、本人普通领券。不用为了测试实际下单或消费。
- [ ] 云闪付/京东金融/铁路12306/携程等域名专项不需MITM；确认没有解密支付或银行主域。微信专项仅命中文章广告，不据此勾选朋友圈/视频号去广告成功。
- [ ] 更新前在本机记录“软件→地区”组名；刷新原公共主配置后，私人URL和关联仍在、地区选择正确。文件默认可能被旧UI选择覆盖；历史旧组名迁移时另按更新教程处理。若选择丢失，记录触发步骤并重选，不发私人预览。
- [ ] 可在设备临时副本中给订阅 URL 填一个 `.invalid` 测试值，观察更新失败是否保留旧缓存；不要在主私人覆写中覆盖真实 URL。首次失败与曾成功后的缓存不是同一情况。
- [ ] “广告拦截→DIRECT”仅放行域名，关闭HTTP/MITM停止HTTP处理，停用Stash停止本项目接管；按当前需求不验收逐App开关。能按教程恢复原可用配置。

- [ ] 更新频率与[统一建议](UPDATES.md)一致：远程广告规则集和机场节点均配置24小时自动尝试刷新；公共主配置每周手动刷新一次，修复发布后立即刷新；内嵌JS随主配置。30分钟节点测速不当作规则更新，断网/后台等情况不承诺准点。
