# 机场订阅、SS 与 VLESS：避免遗漏节点

你的真实机场 URL/token、订阅响应、节点 server/password/uuid 全部只留在 iPhone。不要通过 GitHub Issue、聊天、云验证工具或第三方转换站发送。公开示例只用 `.invalid`、文档保留地址和零值 UUID，不能连接。

## 本项目接受什么

目标格式是包含 `proxies:` 数组的节点 YAML，使用原生代理集“机场”。优先在机场后台选择**明确标为 Stash**且包含所需协议的输出。不要选 Surge/QX 的条目塞给 Stash，也不要将一份 Clash Meta 全配置当作已经兼容。

不同类型不混为一谈：

| 输入 | 本项目处理 | 核实/限制 |
|---|---|---|
| `proxies:` 节点 YAML | 作为远程代理集目标格式；本仓库模拟 SS 与基础 VLESS+TLS+WebSocket 节点 | 云端检查字段结构；真实 Stash 导入/连接必须手机测试 |
| 一整份机场配置（含 groups/rules 等） | 不直接让机场接管本项目分流；请机场提供节点代理集输出 | 当前无法证实 Stash 对所有整份配置的节点提取行为；必须对照节点数 |
| Base64 包裹的 URI 列表 | 不盲目解码或写第三方转换脚本；先核实当前 Stash 原生支持 | 不声称一定不支持；官方文档访问受阻，仍待复核 |
| `ss://`、`vless://` 链接 | 可用于设备单节点诊断；是否能直接作为 proxy-provider 订阅不是同一能力 | 需当前 Stash 原生验证，不当作本项目已验证支持 |
| VLESS+Reality、XTLS/vision、gRPC、特定 packet encoding、SS2022 等 | 不擅自删除字段/改协议/关 TLS；单独核实版本和字段支持 | **未验证**。基础 VLESS 通过结构检查不代表上述组合可用 |

## 第一次接入的最少检查

1. 在 iPhone 机场后台确认期望的节点总数、SS 和 VLESS 各数量。别把“剩余流量/到期提示”当可连接节点。
2. 将 URL 填进下载后**本机私人订阅覆写**的 `proxy-providers → 机场 → url`。provider 名保持“机场”。URL 含 `:`、`#` 等时，整段用单引号包裹；若 URL 本身有单引号，YAML 中用两个连续单引号转义。不要添加 `${TOKEN}` 等未经支持的变量。
3. 在 Stash 中刷新此代理集并查看实际节点数量、协议类型、错误项。出现“配置解析成功”后仍需比较数量；少了 VLESS 节点时不要忽略。
4. 先在“手动节点”里各选一个 SS/VLESS，总代理选“手动节点”，请求普通 HTTPS 网站，检查证书/连接是否正常。若某协议失败，记录 Stash/iOS 版本、协议类型、传输类型与**脱敏后的错误类别**，不要导出全配置。
5. 确认节点名与真实出口地区相符；测速可通不代表 OpenAI/Netflix 解锁，国家旗帜也不是出口证明。

## 遗漏或解析错误

先看原生错误位置，不要把订阅投给未知网站。常见待查项：格式选错、机场按 User-Agent 返回不同内容、VLESS 传输/扩展不支持、SS cipher 不支持、重复节点名或与 DIRECT/REJECT/本项目组名同名、节点更名、订阅返回登录页/错误页、到期、TLS/时钟错误。

如机场没有可用 Stash 输出，请要求它提供目标节点 YAML 和该 Stash 版本支持的协议。不能通过把 Reality 改成普通 TLS、删掉必要字段或设置 `skip-cert-verify` 来“修复”。必要时只启用已在手机验证的节点，未支持的节点明确列为不可用，不能宣称全量兼容。

## 更新失败/改名

本项目请求每日刷新；这不等于失败后一定保留旧数据。检查 Stash 是否仍显示上次成功的节点和时间。**不删除旧代理集，不替换成空列表，不自动直连或跨地区。** 缓存存在且未过期时可继续用已验证节点；缓存失效时停用代理或明确拒绝，修复 URL/账号/网络后再刷新。首次刷新就失败时没有可依赖的旧缓存。

地区池按名字筛选；改名可能退出原池、改变顺序、使手动选择失效。刷新后检查地区数量、总代理和各软件选择。`US01/JP01/HK01/SG01/TW01` 与带分隔符的缩写均纳入筛选；不匹配 Russia、Australia、BUSINESS 等无关单词。缩写仍然不是地理定位，命名不规范时请机场改名或手动选择。`美国入口-日本出口` 等多地区标记会有歧义，本项目不会猜真出口。

开发验证：`python tools/check_provider.py` **只读取公开模拟文件**，输出协议计数，不会下载任何真实订阅，也不是 Stash 验证器。
