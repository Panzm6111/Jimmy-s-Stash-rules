# 下载包的最少操作

本包由同一套主项目生成，功能范围不变，自动签到暂停。公共规则与JavaScript已经放在文件里，不用逐个添加远程链接。希望使用固定链接更新时，优先看[订阅导入教程](SUBSCRIBE.md)；下文是本地文件方式。两种方式都需联网获取你自己的机场订阅和正常使用代理。

1. 在iPhone“文件”App里点开 Jimmy-Stash.zip 解压。
2. 将 Jimmy-Stash.yaml 共享到Stash，作为本地配置导入。编辑它开头的 `url: https://example.invalid/REPLACE_ON_DEVICE`，只在手机替换成你自己的机场订阅链接，保存。
3. 刷新“机场”代理集，核对SS/VLESS等节点数量；把“总代理”从REJECT改成“自动节点”或你需要的地区，选择“规则模式”后连接。“海外AI”默认美国，Netflix/YouTube/Telegram和未匹配流量默认跟随总代理，也可各自独立选择地区；Apple/Microsoft先保持默认DIRECT。
4. 需要淘宝、小红书等开屏专项时，再把同包的“广告增强.stoverride”导入Stash覆写，启用并关联刚才的本地配置。在Stash本机生成CA、按提示安装，并在iOS“设置→通用→关于本机→证书信任设置”信任自己的证书，再启用HTTP/MITM。菜单随版本可能不同。无需在几十款App之间逐个导入。

“自动节点”、五个单地区和“其他地区”均按最近成功HTTPS探测延迟自动选最低者（`url-test`，30分钟检查间隔；原生切换阈值、缓存和时机待实测），不是ICMP ping、下载带宽或服务解锁测试。“自动节点”可跨国家，“其他地区”可在其多个国家间选择，公共筛选并非五地区的严格补集；手选全节点使用“手动节点”。单地区池没有其他国家或DIRECT，REJECT哨兵的原生空池/全失效行为仍待验收。

主配置已经包含分流和基础域名广告拦截，不需要证书。“广告增强”是40个独立App模块的组装入口；只有其中列出的精确主机参与MITM，域名级解密能看到同主机其他内容，不解密银行/支付主域。证书和订阅始终只留在你的设备。微信模块仅含公众号文章，不含朋友圈/视频号。

广告或正常功能异常时，先关闭整个“广告增强”并重建连接。想逐款开关，可停用这份整合覆写，改为只导入“按App单独开关”目录中需要的文件；不要同时启用同款两遍。单App文件也已经内嵌脚本。源码中的模块仍是唯一维护来源，没有另写第二套广告逻辑。

“扩展域名.stoverride”提供38,066条扩展包的本地快照，可选，首次可以先不导入。需要时将其关联到主配置，优先级高于主配置、低于广告增强/私人白名单；最终配置中局域网与系统直连例外应在扩展广告前。原生优先级/合并必须在Stash预览核对。出现误拦就停用它。

“广告拦截→DIRECT”只放行域名规则；HTTP重写或脚本需要停用对应覆写才能停止。实在无法恢复时，切回原来能用的配置或停止Stash，不删除自己的订阅与账号资料。

原来用公共订阅且已能连接的用户，无需为本次调整改成本地包或重填订阅，直接按[一次性迁移说明](UPDATES.md#本次测速与海外ai调整的迁移)刷新原配置。对于本包，“全部节点→自动节点”“OpenAI组→海外AI”后需核对选择；总代理可能回到REJECT，海外AI美国与Apple DIRECT的文件默认不保证覆盖已有UI选择。

这是静态本地快照：机场仍按配置请求更新；内嵌公共规则和脚本不会自己刷新。以后拿到新包时，先在本机备份旧配置、记下各软件地区选择，再在新文件本机填入原订阅并导入，必要时重选地区。不要把含私人URL的旧配置上传。固定订阅入口和远程分层教程另有保留，不是本包的必要步骤。

包内“源码”目录包含维护文件、来源快照、许可证和完整教程；不用逐个导入这些源码文件。独立脚本与规则保持MIT/GPL-2.0/GPL-3.0等各自许可；整包是独立资源的集合，不用项目根MIT重新授权第三方资源。

尚未在你的iPhone验证导入、合并、地区池空/失效行为、连接或去广告效果。内嵌脚本content字段在指向Stash官方文档的历史原生示例中实际存在，旧示例同时标记不再维护、仅推荐开发使用；当前官方文档与精确版本仍受访问条件限制，不能把离线检查说成Stash实测通过。地区池异常先恢复原配置，不以改为直连/跨地区代替处理。
